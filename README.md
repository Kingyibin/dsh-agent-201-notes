# Agent 2.01：能力位地图与原创成果实录

一个跑了半年的自托管 agent 系统，到 `2.01` 算半成熟：QQ 群聊 / 主人私聊 / B 站直播 /
语音房 / 本地画图，共用一个身份与一份记忆；云端跑对话，本地保记忆与素材。

这个仓库是**纯文档**：把「哪些是自己从零写的、哪些是上游或第三方」讲清楚，
并留下可复现的工程结论。**不含任何上游项目的代码**，也不含运行时数据。

## 一句话版本

> 真正特别的不是「接了个大模型」，而是**让同一个 agent 跨机器、跨应用、跨会话保持身份**，
> 并且把「什么时候该醒、什么时候该闭嘴、这一轮花了多少钱」都做成可测的工程约束。

## 能力位 × 来源

| 能力位 | 做什么 | 归属 |
|---|---|---|
| 唤醒决策 | 七级触发、冷却限流、夜间静默、积压补发 | 上游桥接层内的自研增量（代码不在本仓库） |
| 权限面 | 注册期隐藏工具 + 执行期白名单双层守卫 | 同上 |
| preset | 4 套人设，源是唯一权威，产物自动生成并防漂移 | 同上 |
| 记忆压缩 | 把工程交接单式摘要换成「人的记忆」五节输出 | **纯原创独立插件**，见 `dsh-memory-compaction` |
| 云地同步 | 定时快照、防覆盖合并、digest、换窝接管 | **纯原创独立模块**，见 `dsh-cloud-memory-sync` |
| 自托管 | 零公网端口、免扫码重启、systemd、看门狗 | **纯原创独立模块**，见 `dsh-agent-selfhost-kit` |
| 语音 | 本地 ASR + 本地 TTS + 实时推流 | **纯原创独立插件**，见 `dsh-oopz-voice` |
| 成本 | token 账本、峰谷计价、按轮下钻看板 | 上游桥接层内的自研增量（代码不在本仓库） |
| B 站 / 心情 / 主动搭话 | 刷直播、心情挂饰、无人时起话头 | 第三方插件，仅配置与集成 |

## 12 项特有成果（详见 docs/ORIGINAL_WORK.md）

1. 跨机器同一身份的记忆同步与防覆盖合并
2. 不依赖 IDE / 计划任务的纯脚本定时守护
3. 把官方压缩换成「人的记忆」的独立实现
4. NapCat 快速登录只认 `ACCOUNT` 的实测结论与固化脚本
5. Tailscale 零公网端口 + `--accept-dns=false` 的部署约束
6. systemd `HOME` / `SuccessExitStatus` 两条反重启风暴不变量
7. 源与生成物双表示 + `--check` 防漂移机制
8. 双层工具权限守卫 + 真实工具名双向求差
9. 夜间静默窗（只放行点名、聊天豁免、不排 proactive）
10. token 账本与峰谷折算，把一次工具往返算成钱
11. v2.01 等待优化：长轮询一次给足 + 空等两次收尾
12. 可交付第三方复现的测试与审计基线

## 版本与口径

`2.01` 的定位是「成本与稳定性优化版」。所有状态类数字（请求数、压缩次数、磁盘、
服务状态）都会变，引用时**必须带核对时间戳**；本仓库文档里出现的数字都标了核对时间。
